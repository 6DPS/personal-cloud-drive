# DPSir 个人私有智云盘 (Personal Cloud Drive)

> 🚀 简洁、轻量、高性能的私有化个人云盘系统。支持局域网千兆传输、外网远程访问、大文件分片秒传、Office/PDF 原生高清预览、AI 全局检索与 Windows 小主机一键部署。

---

## ✨ 核心特性

- **⚡ 高速传输与断点续传**
  - 支持大文件自动分片（1MB/2MB）、双通道并发上传与失败指数退避重试；
  - 云端哈希快速秒传，避免重复上传相同文件；
  - 下载支持 HTTP 206 Range 断点续传与流式直推，局域网千兆直连可达 100+ MB/s。

- **📑 强大的文档与多媒体原生预览**
  - **Office 系列**：支持 Word (`.docx`)、PowerPoint (`.pptx`)、Excel (`.xlsx`/`.csv`) 原生表格与排版预览；
  - **PDF 与文本**：支持 PDF 在线分页阅读、Markdown、代码、TXT 原生语法高亮与排版；
  - **多媒体与图片**：图片高清灯箱浏览、音视频在线流畅播放与流式拖拽。

- **🔍 AI 智能辅助与全文搜索**
  - 支持毫秒级文件名检索与文本/文档全文关键词搜索；
  - 侧边 AI 智能抽屉面板，与个人知识库对话、文档解析提炼。

- **🔒 安全权限与回收站机制**
  - 单用户/多用户 JWT 安全鉴权，防爆破安全频控；
  - 支持对指定机密文件夹设置独立密码加锁；
  - 完善的回收站防误删机制，支持随时还原或彻底粉碎。

- **🛠️ 专为家庭服务器 / Windows 小主机优化**
  - **程序与数据完全解耦**：代码与数据盘（`PersonalCloudDrive`）物理隔离，随时随地任意换机或扩展硬盘；
  - **一键部署**：自带环境自检、防火墙放行、开机静默守护任务安装；
  - **云端热更新**：双击一键从 GitHub 拉取代码并 3 秒平滑重启。

## 🚀 快速上手

### 1. 本地启动（当前电脑）
直接双击运行工程根目录下的：
```text
start-lan-drive.bat
```
或通过命令行：
```bash
npm install --omit=dev
npm start
```
启动后在浏览器中打开：
- **本机访问**：`http://127.0.0.1:8081`
- **局域网设备**：`http://你的电脑IP:8081`（如 `http://192.168.1.xxx:8081`）

## 🖥️ 迁移到专属服务器 / Windows 小主机

详细教程请参阅：👉 **[Windows小主机部署与迁移指南.md](./Windows小主机部署与迁移指南.md)**

1. **第一步（导出）**：
   在笔记本上运行 `换机迁移与数据打包助手.bat`，将代码包和数据文件夹（`D:\PersonalCloudDrive`）复制到移动硬盘。
2. **第二步（部署）**：
   在小主机上双击运行 `一键部署新电脑(Windows).bat`，自动安装依赖、配置开机自启并启动服务！

## 🔄 GitHub 云端同步与日常迭代

详细协同逻辑与沙盒调试请参阅：👉 **[个人网盘后续开发与版本迭代指南.md](./个人网盘后续开发与版本迭代指南.md)**

```text
【笔记本开发】修改代码 ──(双击 上传到GitHub.bat)──> 【GitHub】 ──(双击 一键云端同步更新.bat)──> 【服务器】3秒热更新
```

1. **在笔记本上修改代码后**：
   双击运行 `上传到GitHub.bat`，自动暂存所有修改并安全推送到 GitHub 私有仓库。
2. **在服务器 / 小主机上升效**：
   双击运行 `一键云端同步更新.bat`，自动拉取最新更新并热重启，数据零影响。

## ⚙️ 核心配置说明 (`.env`)

复制 `.env.example` 为 `.env` 可进行自定义配置：

```env
# 网盘主数据存放根路径（支持任意盘符或移动硬盘）
STORAGE_BASE_ROOT=D:\PersonalCloudDrive

# 监听端口与地址
PORT=8081
HOST=0.0.0.0

# 管理员默认账号
CLOUD_DRIVE_USER=admin
```
