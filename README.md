## ✨ 核心特性

- **⚡ 高速传输与断点续传**
  - 支持大文件自动分片（1MB/2MB）、双通道并发上传与失败指数退避重试；
  - 云端哈希快速秒传，避免重复上传相同文件；
  - 下载支持 HTTP 206 Range 断点续传与流式直推，局域网千兆直连可达 100+ MB/s。

- **📊 精细化存储配额与隐私安全隔离**
  - **全新流线型存储看板**：侧边栏实时呈现容量状态（充裕/预警/告急三档阶梯）、平滑动效进度条、余量胶囊及当前目录文件夹/文件即时计数；
  - **角色级数据隔离**：普通用户严格按个人配额（如 20.0 GB）计算余量与百分比，后端自动脱敏宿主机硬件参数，100% 杜绝服务器物理磁盘泄露；
  - **动态可视化调控**：管理员后台一键调整任意账号配额（10GB、20GB、50GB、100GB、不限或自定义），超额上传毫秒级安全拦截阻断。

- **⭐ 文件与文件夹星标收藏**
  - 支持对高频、重要文件及文件夹一键标星（⭐），快速置顶；
  - 侧边栏专属「我的星标」视图，毫秒级快速筛选聚合所有星标资产，支持多选批量加星与取消。

- **📑 强大的文档与多媒体原生预览 & 极简纯图标设计**
  - **Office 系列**：支持 Word (`.docx`)、PowerPoint (`.pptx`)、Excel (`.xlsx`/`.csv`) 原生表格与排版预览；
  - **PDF 与文本**：支持 PDF 在线分页阅读、Markdown、代码、TXT 原生语法高亮与排版；
  - **多媒体与图片**：图片高清灯箱浏览、音视频在线流畅播放与流式拖拽；
  - **纯图标全局统一操作栏**：预览弹窗与压缩包弹窗统一无文字纯图标设计，AI 一键总结采用 DeepSeek 专属水青色微光质感，尺寸与下载、关闭按钮完美统一 32px 规格对齐。

- **🔍 AI 智能辅助与全文搜索 (DeepSeek 驱动)**
  - 支持毫秒级文件名检索与文本/文档全文关键词搜索；
  - 侧边 AI 智能抽屉面板，与个人知识库全库深度问答、文档一键极速提炼总结。

- **🔒 安全权限与回收站机制**
  - 单用户/多用户 JWT 安全鉴权，防爆破安全频控；
  - **多状态加密文件夹挂锁**：直观区分普通目录与已加锁机密目录，支持独立安全密码；
  - 完善的回收站防误删机制，支持随时还原或彻底粉碎。

- **🛠️ 专为家庭服务器 / Windows 小主机优化**
  - **程序与数据完全解耦**：代码与数据盘（`PersonalCloudDrive`）物理隔离，随时随地任意换机或扩展硬盘；
  - **一键部署**：自带环境自检、防火墙放行、开机静默守护任务安装；
  - **云端热更新**：双击一键从 GitHub 拉取代码并 3 秒平滑重启。

## 🚀 快速上手

直接双击运行根目录下的：
```text
start-lan-drive.bat
```
或通过命令行：
```bash
npm install
npm start
```
启动后在任意浏览器中打开：
- **本机极速访问**：`http://127.0.0.1:8081`
- **局域网其他设备（手机/平板）**：`http://你的电脑IP:8081`（如 `http://192.168.1.xxx:8081`）

## 🖥️ 新主机 / 新用户 极速部署指南 (Quick Deployment)

如果你在另一台新电脑（如 Windows 小主机、家庭服务器或闲置电脑）上全新部署本项目：

### 1. 克隆或下载代码
```bash
git clone https://github.com/6DPS/personal-cloud-drive.git
cd personal-cloud-drive
```
*(或者点击 GitHub 绿色按钮 Code ➔ Download ZIP 解压)*

---

### 2. 个性化环境配置 (`.env`)
在项目根目录下复制一份 `.env.example`，命名为 **`.env`**：

```env
# 1. 真实数据存储盘符（支持任意硬盘或移动硬盘，首次启动会自动初始化）
STORAGE_BASE_ROOT=D:\PersonalCloudDrive

# 2. 超级管理员初始账号与密码（首次部署的超级管理员凭据）
CLOUD_DRIVE_USER=admin
CLOUD_DRIVE_PASSWORD=admin123456

# 3. DeepSeek AI 引擎 API Key（启用 AI 全库问答与文档一键极速总结）
# 可在 DeepSeek 开放平台 (https://platform.deepseek.com/) 申请
# 填好保存后，网盘全自动调用，网页前端零配置！
DEEPSEEK_API_KEY=sk-your_deepseek_api_key_here

# 4. 服务监听端口与地址（默认无需修改）
PORT=8081
HOST=0.0.0.0

# 5. 公网域名（选填，若配置了 Cloudflare 等公网加密隧道）
PUBLIC_ACCESS_URL=https://pan.yourdomain.com
```

> 💡 **提示**：若未手动创建 `.env`，直接启动系统也会自动采用开箱即用默认值（超级管理员账号 `admin` / 初始密码 `admin123456`，存储路径 `D:\PersonalCloudDrive`）。

---

### 3. 一键初始化与启动

* **🪟 Windows 电脑 / 小主机**：直接双击运行根目录下的 👉 **`一键部署新电脑(Windows).bat`**（自动唤起 UAC 提权一键确认，自动全网络放行防火墙，开箱即用）
* **🍎 苹果 Mac 电脑 (Apple Silicon M系列 / Intel)**：直接双击运行根目录下的 👉 **`一键部署新电脑(Mac).command`**

向导会自动完成以下工作：
* ✓ 自动检测并安装 Node.js LTS 运行环境（若电脑未安装，会自动静默安装/引导）；
* ✓ 自动安装项目运行依赖包（`npm install`）；
* ✓ 智能绑定数据盘路径（Windows 推荐 `D:\PersonalCloudDrive`，Mac 推荐 `~/PersonalCloudDrive`）并初始化/接管历史数据库；
* ✓ **全网络防火墙自动放行（公用网络+专用网络+域）**：彻底解决 Windows 插网线与连 Wi-Fi 时的网络权限切换冲突，确保全家设备 100% 互联；
* ✓ 自动安装开机后台静默自启守护任务（Windows 任务计划 / macOS launchd 守护进程）。

部署完成后，在浏览器中打开：
* **本机访问**：`http://127.0.0.1:8081`
* **局域网设备（手机/平板/电脑）**：`http://你的电脑IP:8081`（如 `http://192.168.1.xxx:8081`，**手机端请务必完整输入开头的 `http://`**）
* **公网远程访问（若配置了穿透）**：直接打开域名（如 `https://dpsirperson.085410.xyz`）

## 🔑 账号权限与新用户注册体系

* **超级管理员身份识别**：
  * 使用上面设定的管理员账号（默认 `admin` / `admin123456`）登录；
  * 登录成功后，左侧导航栏会**独占显示【🔑 注册密钥管理】按钮**，代表最高管理权限。
* **安全防刷注册体系**：
  * 本系统默认防止外网陌生人随意注册，新用户注册必须提供有效密钥；
  * 管理员进入【注册密钥管理】，可一键生成 15 分钟临时有效的一次性注册密钥，并发放给家人或朋友；
  * 家人/朋友凭借密钥即可注册独立的云盘账户，数据物理隔离，互不干扰。
* **全自动 AI 深度赋能**：
  * 只要在 `.env`（或 Windows 系统用户环境变量）中配置了 `DEEPSEEK_API_KEY`，网盘所有用户即可随时使用 **AI 知识库全库对话** 与 **文档一键深度提炼总结**，全自动流式打字输出，无需任何前端二次设置。
* **子账号存储空间配额与动态调控（管理员专属特权）**：
  * **权限绝对隔离**：管理员（`admin`）拥有全盘最高控制权，存储空间永久无限制；普通子账号无权查看或调用配额管理接口；
  * **动态可视化管理**：管理员侧边栏独占显示【👥 用户配额管理】按钮，实时呈现所有用户（含已注册老用户）当前占用的真实硬盘空间，支持随时在线调整配额（10GB、20GB、50GB、100GB、无限制或自定义大小）；
  * **注册自动绑定与全链路超限防御**：生成注册密钥时可预设配额；普通用户在普通上传、分片续传或秒传超出配额时会被系统毫秒级安全拦截，彻底杜绝服务器物理硬盘被挤爆。
* **随时修改密码**：
  * 任何时候想修改密码，直接在登录页面点击 **【找回密码】**，输入当前密码即可立即设定任意新密码；
* **物理防丢钥匙（密码彻底遗忘的自救兜底机制）**：
  * 这是专为物理机主人预留的最高特权通道。即使彻底忘记管理员密码，只要在服务器电脑的 `.env` 中写入 `CLOUD_DRIVE_PASSWORD=你的备用密码` 并重启网盘，即可在网页端“找回密码”中以此作为恢复密码强行重设，永远无需担心被锁在系统门外！

## ❓ 常见问题与运维维护 (FAQ & Troubleshooting)

### 1. 如果只是临时测试，想彻底停止或删除网盘时提示“文件夹正在被使用”怎么办？
* **原因**：网盘服务正在后台默默守护运行，占用着日志和端口句柄，Windows 会保护正在运行的文件夹禁止删除。
* **一键彻底解决**：
  直接双击根目录下的 👉 **`彻底卸载并停止服务(Windows).bat`**  
  该脚本会：
  1. 自动注销 Windows 开机计划任务自启动；
  2. 自动安全终止后台常驻的 `node.exe` 进程并释放所有端口与文件句柄。
  运行完毕后，即可直接右键删除项目文件夹和数据文件夹，**绝不会再提示“被使用”**！
  *(应急命令行：`taskkill /F /IM node.exe`)*

### 2. 同一个 Wi-Fi / 局域网下，两台电脑都部署了网盘会冲突吗？
* **完全不会！** 家里的无线路由器（DHCP）会给每台电脑分配**完全独立、互不重复的局域网 IP**（如笔记本是 `192.168.1.101`，新主机是 `192.168.1.105`）。
* 两台电脑各自监听各自网卡的 8081 端口，在同一个 Wi-Fi 下同时开机完全互不干扰。输入谁的 IP 就进入谁的网盘。

### 3. 电脑只有 C 盘（没有 D 盘），能一键部署吗？
* **完美支持！** 一键部署向导内置智能磁盘探测机制，会自动优先探测 `D:\`、`E:\` 等大容量数据盘；若电脑只有一个 C 盘，会自动无感适配为 `C:\PersonalCloudDrive`，100% 避免因无 D 盘导致的崩溃。

### 4. Windows PowerShell 中文编码说明
* 本项目全套 20 个 PowerShell 自动化运维脚本均已规范注入 **UTF-8 BOM 签名**，并在批处理头部统一启用 `chcp 65001`，完美兼容中文版 Windows 10/11 系统的 PowerShell 5.1，杜绝 GBK 代码页解析中文字符导致的任何语法报错。

### 5. 如果以后不小心把管理员密码彻底忘了，怎么重置找回？（物理兜底恢复法）
* **原理**：外网用户只能看网页，绝不可能碰你电脑的物理硬盘；系统将本地 `.env` 文件视为最高特权物理钥匙。
* **极简方案（甚至不用点找回密码）**：
  1. 坐在电脑前，用记事本打开网盘根目录的 **`.env`** 文件，加入或修改：
     ```env
     CLOUD_DRIVE_PASSWORD=你的新密码
     ```
### 6. 为什么手机在局域网输入 IP 无法打开，而电脑本机可以打开？
* **原因 1：手机浏览器自带“HTTPS 强制升级”**
  现在的手机浏览器（如 Safari、Chrome）默认开启了“强制 HTTPS”，若在地址栏只输入了 `192.168.x.x:8081`，手机会自动偷换成 `https://` 导致协议握手失败。
  👉 **解决办法**：在手机浏览器地址栏输入时，务必完整输入开头的 `http://`（例如 `http://192.168.0.102:8081`）。
* **原因 2：电脑插拔网线导致 Windows 网络类型切换（公用 ➔ 专用）**
  Windows 会把新插的网线识别为“专用网络”，若之前防火墙仅允许了公用网络，就会在底层拦截手机访问。
  👉 **解决办法**：双击根目录下的 👉 **`allow-lan-firewall-as-admin.bat`** 一键全网络放行，或直接使用已升级的 `start-lan-drive.bat`（自带智能自愈放行）。
* **原因 3：电脑开启了全局 VPN 接管了出口路由**
  部分 VPN 开启 TUN 虚拟网卡后会接管网络回包。
  👉 **解决办法**：在手机上直接打开专属公网加密域名（如 `https://dpsirperson.085410.xyz`），完全无视本地局域网环境与 VPN 干扰，秒级极速直达。
